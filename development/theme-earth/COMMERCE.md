# 2333 Store 商城主题

在 Halo 后台的「外观 → 主题 → 2333 Store → 设置」配置商城参数。修改本机 settings.yaml 后需重载主题，使 Setting 与后台表单同步。模板修改通过容器挂载生效，生产环境需要重新安装主题包。

## 商城首页

- 标题、介绍和每行列数控制 /shop 的整体展示。
- 模块数组的顺序就是页面顺序；关闭模块可临时隐藏。
- 轮播：配置图片、标题和点击链接，可添加多张图片横向展示。
- 分类导航：显示插件后台维护的分类。
- 精选商品：只显示商品管理中勾选「精选商品」且已上架的商品。
- 商品网格：显示上架商品；分类填写商品分类页中的分类标识，数量限制在筛选后应用。
- 推广：配置图片和跳转链接。

## 商品详情

图库可放左侧或上方；可控制库存、商品类型、购买栏吸顶、按钮文字、商品说明、售后说明和相关推荐。相关推荐优先选取同分类商品，排除当前商品。移动端为单列展示。

商品规格、价格与库存来自插件，不放在主题设置中。数字商品兑换码在商品管理的 SKU 中逐行录入；上架数字 SKU 的可售库存不能超过兑换码数量。公开目录接口只返回商品展示字段，不返回兑换码。登录后创建订单会保存价格快照并保留库存 15 分钟；易支付回调验签成功后原子扣减库存并分配兑换码，买家只能在订单页读取自己的已付款订单交付内容。实物付款后进入履约中；「商城 → 订单管理」可登记承运商和物流单号，再确认送达，买家订单页显示物流进度。混合订单须等实物送达后才完成。订单页也可以取消待付款订单。超时或已取消订单发生迟到付款时会标记待退款，需要商家人工退款。

## 本机部署与验证

源码位于 development/theme-earth；编译产物为 templates 和 dist/theme-earth-1.18.0.zip。挂载主题位于 themes/theme-earth。当前 `compose.dev.yaml` 将编译模板挂载到 Halo，并在开发模式从源码加载商城插件；完整操作步骤和数据备份命令见 plugins/plugin-commerce/INSTALL.md。

本机已验证 Halo 2.26 能启停 commerce 插件、完整渲染 2333 Store `/shop` 页面、加载主题 CSS，并让 `/shop/api/products` 返回 200。当前商品目录为空。录入商品后再检查 `/shop/products/{slug}`、购物车、结账和订单页面。

首页模块配置位于「外观 → 主题 → 2333 Store → 设置 → 商城首页」；详情控制位于「商品详情」。后台设置保存/重开后的值回读、商品录入和实物/数字/混合订单的管理端到端流程仍需使用 Halo 管理账号验证。已有测试覆盖配置规范化、模块筛选与顺序、商品详情模板和布局契约。

## 统一管理入口与支付配置

主题顶部提供商品管理、商品分类、订单管理及支付管理。前三个标签可进入插件对应业务页；支付管理直接保存易支付参数。商户密钥通过 Halo Secret 保存，键名为 merchant_key，主题 ConfigMap 仅保存 Secret 名称。保存后插件按请求读取最新配置，无需重启。关闭支付只暂停新支付，仍处理已发起订单的验签回调。未保存该配置组的旧安装兼容环境变量；首次保存后主题设置成为配置来源。

显示名称、作者及项目链接已替换；内部 theme-earth ID 保留，以继续使用现有配置与主题绑定。基于 Earth 的开源版权及 GPL-3.0 保留。

「插件集成」明确列出配套 commerce 插件，提供插件详情与启用状态、商城页面入口。该页面是主题的显式集成说明，不会自动枚举已安装插件。

商品管理、商品分类和订单管理通过 commerce 插件的全局 Vue 组件直接显示在主题设置中，使用相同 API 和权限。分类管理首次打开时幂等创建商城默认分类；不会覆盖已有同名分类。

### 商城首页四个区块

在商城首页的「首页模块」中编辑幻灯片、分类导航、商品网格、图文推广，可排序和控制显示。
幻灯片的「左侧大图轮播列表」支持多张图片及各自链接；右侧上图、下图各自支持图片、说明、链接。图片可上传、从附件库选择或输入地址。
桌面默认左／右 2:1、右侧上下 1:1、高度 420px、间距 16px；可独立调整，图片支持裁剪填满或完整显示。自动切换间隔 0 可关闭，鼠标悬停和键盘聚焦时暂停。手机大图按配置宽高比显示，右侧两图移到下方。
图文推广默认关闭，配置图片、说明和链接后可启用。商品网格支持分类筛选、数量及全局列数，分类导航读取商城商品分类。
验证轮播逻辑：`node --test tests/store-hero.test.mjs`。
