# 2333 Store

cnmbdb 自主开发的 Halo 商城主题，支持实物和数字商品。配合本仓库的 commerce 插件使用。

在「外观 → 主题」中统一进入商品管理、订单管理、支付管理、商城首页和商品详情设置。顶部管理标签提供对应业务页面的入口；支付参数在主题内保存并立即生效，商户密钥引用 Halo Secret 中的 `merchant_key`。

源码仓库：https://github.com/cnmbdb/halo

开发和部署步骤见 [COMMERCE.md](./COMMERCE.md) 与 [插件安装说明](../../plugins/plugin-commerce/INSTALL.md)。主题内部 ID 保留为 `theme-earth`，以延续现有主题设置和菜单绑定。
